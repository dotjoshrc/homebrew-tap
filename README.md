# homebrew-tap

Homebrew tap for [dotjoshrc](https://github.com/dotjoshrc) tools.

## Formulae

| Formula | Description |
| --- | --- |
| [`sbx-connect`](https://github.com/dotjoshrc/sbx-connect) | Connect ACP editors to coding agents in Docker Sandboxes |
| [`easy-params`](https://github.com/dotjoshrc/easy-params) | Opinionated CLI for easy management of SSM Parameters |

## Install

```sh
brew install dotjoshrc/tap/sbx-connect
brew install dotjoshrc/tap/easy-params
```

Or tap once and install by name:

```sh
brew tap dotjoshrc/tap
brew install sbx-connect
```

Binaries are provided for macOS and Linux on both arm64 and amd64.

## Notes

- `sbx-connect` requires Docker Sandboxes to be installed separately and authenticated with `sbx login`. To connect Zed, run `sbx-connect install zed`.
- The formulae in `Formula/` are generated by each project's release tooling (`go run ./scripts/homebrew-formula`) and should not be edited by hand.
